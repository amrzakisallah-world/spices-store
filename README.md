# " توابل أصلي "  للتوابل — Spices Store (Tawabil Asly)

متجر إلكتروني عربي (RTL) + لوحة تحكم خاصة للمالك لإدارة المبيعات والمصروفات والأرباح والمخزون وأسعار الموردين (حراز وغيره).

**التقنية:** Cloudflare Workers (API) + D1 (قاعدة بيانات SQLite) + R2 (صور المنتجات) + واجهة HTML/JS بدون أي مكتبات خارجية.
الخادم **بلا أي dependencies** (الاعتماد الوحيد للتطوير هو `wrangler`)، وده بيقلل المخاطر والتعقيد.

> الحالة: الكود مُختبر محليًا (157 اختبار API + اختبار متصفح حقيقي). **النشر على Cloudflare نفسه لم يُجرَّب** لأنه يحتاج حسابك — اتبع الخطوات تحت.

---

## 1) المميزات

**المتجر (للعملاء):** عربي RTL أولًا وموبايل أولًا · أقسام · بحث عربي ذكي (يتجاوز الهمزات والتاء المربوطة) · صفحة منتج بصور · الأسعار والتوفر من قاعدة البيانات · سلة بتفضل محفوظة · إتمام الطلب (الاسم، الموبايل، العنوان، ملاحظات) · كود طلب + صفحة تتبع الحالة (بالكود + رقم الهاتف) · زر واتساب (لو اتضبط) · حماية من السبام (honeypot + حد للمحاولات).

**لوحة التحكم (`/admin/`):**
- **الرئيسية:** مبيعات يومي/أسبوعي/شهري/سنوي مع مقارنة بالفترة السابقة · الإيراد · تكلفة البضاعة · إجمالي الربح · المصروفات · **صافي الربح** · المستحقات (عملاء وموردين) · رصيد النقدية · رسوم بيانية · تنبيهات (مخزون منخفض، طلبات جديدة، ارتفاع أسعار مورد، منتج بيعه أقل من تكلفته…).
- **الطلبات:** بحث وفلترة · تغيير الحالة · تسجيل دفعات (جزئية/كاملة، فودافون كاش، إنستاباي…) · تكلفة التوصيل · خصم · إلغاء مع إرجاع المخزون ورد المبلغ.
- **المنتجات:** إضافة/تعديل/حذف · رفع صور (تُصغَّر تلقائيًا من الموبايل) · أقسام · سعر البيع والتكلفة · المخزون وحركته · سجل تغيّر الأسعار · إخفاء/إظهار.
- **المالية:** قائمة دخل (أرباح وخسائر) يومي/شهري/سنوي لسنين طويلة · مصروفات بتصنيفات · دفتر نقدية · تصدير CSV (يفتح في Excel بالعربي) · طباعة/PDF من المتصفح.
- **الموردون والأسعار (حراز):** سجل موردين · **سجل أسعار تاريخي لكل صنف** · نسبة التغيّر عن آخر سعر · مقارنة التكلفة بسعر البيع وهامش الربح · فواتير شراء (تزوّد المخزون وتحدّث التكلفة اختياريًا) · مستحقات الموردين.
- **الإعدادات:** رسوم التوصيل · حد التوصيل المجاني · واتساب · مستخدمين (مالك/موظف) · تغيير كلمة المرور.

> **ملاحظة مهمة عن أسعار حراز:** لا يوجد ربط مباشر بأسعار السوق ولا يدّعي المشروع ذلك. الأسعار **تُدخل يدويًا** (أو من فاتورة شراء) وتتحفظ كلها للمقارنة التاريخية.

## 2) كيف تُحسب الأرباح (لا نخلط الإيراد بالربح)

| البند | التعريف |
|---|---|
| الإيراد | إجمالي الطلبات بحالة **تم التسليم** (حسب يوم التسليم) |
| تكلفة البضاعة (COGS) | مجموع (تكلفة الوحدة وقت البيع × الكمية) |
| إجمالي ربح المنتجات | (المنتجات − الخصم) − تكلفة البضاعة |
| هامش التوصيل | رسوم التوصيل المحصّلة − تكلفة التوصيل الفعلية |
| **صافي الربح** | إجمالي الربح + هامش التوصيل − المصروفات التشغيلية |
| التدفق النقدي | حركات فعلية من دفتر النقدية (دفعات، رد مبالغ، مصروفات، دفعات موردين) |

- مشتريات المخزون **ليست مصروفًا** (حتى لا تُحسب مرتين): تدخل في الربح عبر تكلفة ما بِيع.
- سعر وتكلفة كل صنف **يُنسخان داخل الطلب وقت البيع**، فتغيير السعر لاحقًا لا يغيّر تاريخ الطلبات.
- كل المبالغ تُخزَّن **أعدادًا صحيحة بالقروش** (1 جنيه = 100) لتفادي أخطاء الكسور العشرية.

## 3) الحسابات والخدمات الخارجية المطلوبة

| الخدمة | لماذا | تكلفة |
|---|---|---|
| حساب **Cloudflare** | الاستضافة + D1 + R2 | مجاني للبداية (R2 قد يطلب إضافة وسيلة دفع، لكن الحد المجاني كبير) |
| حساب **GitHub** | حفظ الكود | مجاني |
| رقم **واتساب** (اختياري) | زر التواصل | — |
| دومين (اختياري) | عنوان مخصص | حسب المسجّل |

لا يوجد أي مفتاح API لطرف ثالث مطلوب. **لم أخترع أي بيانات اعتماد.**

## 4) متغيرات البيئة والأسرار

| الاسم | النوع | الوصف |
|---|---|---|
| `SETUP_TOKEN` | **Secret** (إلزامي) | نص عشوائي طويل (16+ حرف) يُستخدم **مرة واحدة** لإنشاء حساب المالك. بعد إنشائه يتعطل التسجيل نهائيًا. |
| `DB` | D1 binding | قاعدة البيانات (في `wrangler.toml`) |
| `IMAGES` | R2 binding | صور المنتجات (في `wrangler.toml`) |

محليًا: انسخ `.dev.vars.example` إلى `.dev.vars` (الملف ده في `.gitignore` ولا يُرفع أبدًا).
على الإنتاج: `npx wrangler secret put SETUP_TOKEN` أو من لوحة Cloudflare ← Settings ← Variables and Secrets.

## 5) التشغيل المحلي

يحتاج Node 20+.

```bash
npm install
npm test            # اختبارات الـ API (157 فحص) — بدون إنترنت
npm run local       # معاينة سريعة على http://localhost:8787 (قاعدة SQLite محلية)
```
افتح `http://localhost:8787/admin/` ← تظهر شاشة إنشاء المالك، رمز الإعداد المحلي الافتراضي: `local-dev-setup-token-123`.

أو بنفس بيئة Cloudflare الحقيقية:
```bash
cp .dev.vars.example .dev.vars        # عدّل SETUP_TOKEN
npm run db:migrate:local
npm run dev
```

## 6) النشر على Cloudflare

```bash
npm install
npx wrangler login
npx wrangler d1 create spices-store-db          # انسخ database_id إلى wrangler.toml
npx wrangler r2 bucket create spices-store-images
npm run db:migrate:remote                       # ينشئ الجداول
npx wrangler secret put SETUP_TOKEN             # الصق نصًا عشوائيًا طويلًا
npm run deploy
```
ثم افتح `https://<اسم-الـworker>.workers.dev/admin/` وأنشئ حساب المالك.

**من الموبايل (بدون كمبيوتر):** لوحة Cloudflare (dash.cloudflare.com) ← Storage & Databases ← **D1** ← Create database باسم `spices-store-db` ← انسخ الـ ID وضعه في `wrangler.toml` على GitHub ← Console ← الصق محتوى `migrations/0001_init.sql` ونفّذه ← **R2** ← Create bucket باسم `spices-store-images` ← Workers & Pages ← Create ← **Import a repository** واختر المستودع (Deploy command: `npx wrangler deploy`) ← Settings ← Variables and Secrets ← أضف Secret باسم `SETUP_TOKEN`. *(هذا المسار لم يُجرَّب من طرفي؛ لو ظهرت رسالة خطأ ابعتها لي.)*

**بيانات تجريبية (اختياري):** `npx wrangler d1 execute spices-store-db --remote --file=scripts/demo-data.sql` — مُعلَّمة DEMO وأسعارها وهمية، احذفها قبل الإطلاق.

## 7) أول إعداد بعد النشر
1. `/admin/` ← أنشئ المالك (الاسم، البريد، كلمة مرور 10+ أحرف، SETUP_TOKEN).
2. الإعدادات: رسوم التوصيل، حد التوصيل المجاني، رقم واتساب (مثال `201012345678`).
3. المنتجات ← الأقسام ← أضف الأقسام ثم المنتجات وصورها وتكلفتها.
4. الموردون: تم إنشاء مورد «حراز» تلقائيًا — سجّل أسعاره من تبويب «أسعار الموردين».
5. حساب موظف (اختياري): الإعدادات ← مستخدم جديد ← «موظف» (يرى الطلبات والمنتجات فقط، ولا يرى التكاليف ولا المالية).

## 8) رفع المشروع إلى GitHub من أندرويد

GitHub على الموبايل **لا يفك ملفات ZIP ولا يرفع مجلدات**، فأضمن طريقتين:

**الطريقة الأسهل — Codespaces (من متصفح الموبايل):**
1. من Chrome افتح `https://github.com/amrzakisallah-world/spices-store` ← فعّل «Desktop site» من قائمة ⋮.
2. اضغط **Code ← Codespaces ← Create codespace on main** (حد مجاني شهري).
3. في شاشة VS Code: اسحب/ارفع ملف الـ ZIP إلى الـ Explorer (أو Upload من قائمة الملفات).
4. افتح Terminal وشغّل:
   ```bash
   unzip -o spices-store.zip -d . && rm spices-store.zip
   git add -A && git commit -m "Initial Spices Store" && git push
   ```
   (لو الـ ZIP فكّ داخل مجلد فرعي `spices-store/` انقل محتواه: `mv spices-store/* spices-store/.[!.]* . && rmdir spices-store`).
5. اقفل الـ Codespace (Stop) بعد الانتهاء.

**بديل — Termux:** ثبّت Termux من F-Droid ثم `pkg install git unzip`، فُكّ الـ ZIP، `git init && git remote add origin https://github.com/amrzakisallah-world/spices-store.git && git add -A && git commit -m init && git push -u origin main` (سيطلب Personal Access Token بدل كلمة المرور من GitHub ← Settings ← Developer settings).

⚠️ قبل أول push تأكد أن `git status` لا يُظهر `.dev.vars` أو `.env` أو `node_modules` (الـ `.gitignore` يمنعها).

## 9) الأمن
- لا تسجيل عام للإدارة: إنشاء المالك مرة واحدة فقط برمز سري، وبعدها مغلق.
- كلمات المرور PBKDF2-SHA256 (100,000 دورة + salt عشوائي) · الجلسة كوكي `HttpOnly` + `SameSite=Strict` + `Secure` وتُخزَّن في القاعدة كـ hash فقط · أسبوع صلاحية.
- كل API إداري يتحقق من الجلسة والصلاحية على الخادم (مالك/موظف) + حماية CSRF (رأس مخصص + فحص Origin).
- حد محاولات لتسجيل الدخول والطلبات العامة والتتبع · honeypot ضد البوتات · تتبع الطلب يحتاج الكود + رقم الهاتف.
- تحقق من المدخلات في المتصفح **وفي الخادم** · كل النصوص تُعرض بعد escaping (ضد XSS) · تصدير CSV محمي من حقن المعادلات.
- رؤوس أمان + Content-Security-Policy صارمة (`public/_headers`) · الصور تُفحص بالـ magic bytes.
- لا أسرار في الكود ولا في GitHub.

## 12) حدود معروفة (بصراحة)
- **لم يُنشر على Cloudflare فعليًا** ولم يُختبر `wrangler dev/deploy` (غير متاح عندي). الاختبارات تعمل على محاكي D1/R2 مطابق في الواجهة.
- لا دفع أونلاين: الدفع نقدًا عند الاستلام، ويُسجَّل يدويًا (فودافون كاش/إنستاباي تُسجَّل كدفعات). ربط بوابة دفع يحتاج حساب بوابة ومفاتيحها.
- لا أسعار حراز تلقائية (إدخال يدوي فقط).
- المنتج الواحد = وحدة بيع واحدة (250 جم و500 جم منتجان منفصلان).
- لا إشعارات تلقائية (واتساب/بريد) للطلبات الجديدة؛ تظهر في لوحة التحكم وتنبيهاتها.
- الصور الحالية رسومات بديلة (وعاء بهارات) حتى ترفع صور المنتجات الحقيقية.
- الخطوط من Google Fonts (تحتاج إنترنت العميل؛ لها بدائل نظام).
- لا تصدير PDF/Excel أصلي (CSV + طباعة المتصفح).
