# Spices Store — متجر عمر و يونس للتوابل والبهارات

تطبيق تجارة إلكترونية متكامل ونظام إدارة أعمال يومية لمتجر **توابل أصلي (Omar & Younis Spices)**، مبني بـ **React + TypeScript + Tailwind CSS + Express + SQLite**.

---

## المزايا الرئيسية

### 1. واجهة العملاء (Storefront)
- **واجهة عربية RTL متجاوبة بالكامل** مع دعم اللغة الإنجليزية.
- **كتالوج حي من قاعدة البيانات**: 37 صنفاً من التوابل والبهارات والأعشاب بأسعار دقيقة (تمن كيلو 125 جم، ربع كيلو 250 جم، نص كيلو 500 جم، 1 كجم).
- **قائمة الطلب السريع**: إضافة التوابل الأساسية بضغطة واحدة من الهاتف.
- **سلة مشتريات وإتمام طلب سريع**: حساب رسوم التوصيل والتوصيل المجاني تلقائياً من قاعدة البيانات، مع دعم الدفع عند الاستلام، إنستا باي، وفودافون كاش.
- **تتبع الطلبات**: استعلام آمن برقم الطلب ورقم الهاتف.
- **تكامل واتساب (اختياري)**: يظهر زر إرسال الطلب عبر واتساب عند ضبط رقم الواتساب في الإعدادات.

### 2. لوحة تحكم الإدارة (Admin Dashboard — `/admin`)
- **ملخص الأداء والأرباح**: مبيعات اليوم/الأسبوع/الشهر/السنة، مع فصل دقيق بين **الإيرادات (Revenue)** و**مجمل الربح (Gross Profit)** و**صافي الربح (Net Profit)** بعد خصم التكلفة الفعلية والمصروفات التشغيلية.
- **إدارة المنتجات والمخزون**: إضافة وتعديل وحذف/إيقاف المنتجات، تسجيل سعر البيع وتكلفة الشراء، تتبع هامش الربح والحد الأدنى للمخزون، ورفع صور حقيقية للمنتجات من كاميرا الهاتف أو المعرض.
- **إدارة الطلبات والمدفوعات**: تحديث حالات الطلب، استرجاع المخزون تلقائياً عند الإلغاء، تسجيل التحصيلات (كلي/جزئي)، وتسجيل تكلفة الشحن الفعلية.
- **المصروفات والتقارير المالية (P&L)**: تسجيل المصروفات المصنفة والإيرادات اليدوية، دفتر الحركات النقدية، وتصدير التقارير بصيغة CSV متوافقة مع العربية في Excel.
- **إدارة الموردين وتتبع أسعار الحراز**: تسجيل أسعار الموردين يدوياً وتاريخياً (مع عطار الحراز كمورد رئيسي)، مقارنة السعر الحالي بالسابق وبسعر البيع، وتسجيل فواتير الشراء التي تزيد المخزون تلقائياً.

## متغيرات البيئة المطلوبة (`.env`)

انسخ ملف `.env.example` إلى `.env` وقم بتعديل القيم قبل التشغيل الإنتاجي:

| المتغير | الوصف | مثال |
|---|---|---|
| `PORT` | منفذ الخادم | `3000` |
| `DATABASE_PATH` | مسار ملف قاعدة البيانات SQLite | `./data/spices-store.db` |
| `SESSION_SECRET` | مفتاح عشوائي طويل لتوقيع الجلسات | `your-random-64-char-secret` |
| `ADMIN_NAME` | اسم حساب المالك الأولي | `مدير المتجر` |
| `ADMIN_EMAIL` | البريد الإلكتروني لتسجيل الدخول للإدارة | `admin@omaryounis.com` |
| `ADMIN_INITIAL_PASSWORD` | كلمة المرور الأولية عند إنشاء القاعدة لأول مرة | `StrongPassword2026!` |
| `WHATSAPP_NUMBER` | رقم واتساب المتجر بالصيغة الدولية بدون `+` (اختياري) | `201001234567` |
| `STORE_PHONE` | رقم هاتف المتجر (اختياري) | `01001234567` |
| `STORE_ADDRESS` | عنوان المتجر | `القاهرة، مصر` |
| `DEFAULT_DELIVERY_FEE_EGP` | رسوم التوصيل الافتراضية بالجنيه | `45` |
| `FREE_DELIVERY_THRESHOLD_EGP` | حد الطلب للتوصيل المجاني بالجنيه | `600` |

> **تحذير أمني:** لا تقم أبداً برفع ملف `.env` أو ملفات قاعدة البيانات (`data/*.db`) إلى GitHub.

## قاعدة البيانات والتهجير (Database & Migrations)

- ملف التهجير الأولي: `db/migrations/001_initial.sql`
- يتم تشغيل التهجير تلقائياً عند تشغيل الخادم عبر `server/db.ts` مع تفعيل `PRAGMA foreign_keys = ON`.
- جميع القيم المالية تُخزن بوحدة **القرش (`piasters`)** كأعداد صحيحة لضمان دقة الحسابات المالية بدون أخطاء الكسور العشرية.

## التثبيت والتشغيل المحلي

```bash
# 1. تثبيت الحزم
npm install

# 2. إنشاء ملف البيئة
cp .env.example .env

# 3. التشغيل في وضع التطوير (Frontend + Backend معاً على منفذ 3000)
npm run dev
```

### التشغيل في بيئة الإنتاج (Production)

```bash
# 1. بناء الواجهة الأمامية
npm run build

# 2. تشغيل الخادم الإنتاجي
npm start
```

## إعداد حساب الإدارة والبيانات التجريبية

1. لوحة الإدارة مخفية بالكامل عن واجهة العملاء؛ للدخول افتح المسار `/admin` مباشرة في الرابط.
2. عند أول تشغيل لقاعدة البيانات، يتم إنشاء حساب المالك من `ADMIN_EMAIL` و`ADMIN_INITIAL_PASSWORD` (وفي حال عدم ضبطهما في بيئة التطوير يستخدم `admin@omaryounis.com` و`ChangeMe123!`).
3. **في حال نسيان كلمة المرور**:
   - عبر المتصفح: اضبط المتغير `ADMIN_RESET_KEY` في ملف `.env` ثم استخدم خيار «نسيت كلمة المرور؟» في صفحة `/admin`.
   - أو عبر الطرفية على الخادم: `npm run reset-admin -- admin@omaryounis.com NewPassword123`
4. تأتي القاعدة مزودة بكل الأصناف الـ 37 الحقيقية، مع عدد محدود من الطلبات والمصروفات التجريبية المميزة بوسم `[تجريبي]`. عند البدء الفعلي يمكنك مسحها بضغطة زر من **إعدادات المتجر ← حذف البيانات التجريبية**.

## خطوات رفع المشروع إلى GitHub من الهاتف (Android)

1. قم بتحميل ملف الـ ZIP المرفق (`spices-store-source.zip`) إلى هاتفك وفك الضغط عنه باستخدام تطبيق مدير الملفات (مثل Files by Google أو ZArchiver).
2. افتح مستودعك على GitHub في متصفح الهاتف:
   `https://github.com/amrzakisallah-world/spices-store-ma`
3. لرفع الملفات عبر المتصفح:
   - اضغط **Add file** ← **Upload files** (أو استخدم تطبيق Git على Termux: `git init`, `git add .`, `git commit -m "Initial Spices Store"`, `git remote add origin https://github.com/amrzakisallah-world/spices-store-ma.git`, `git push -u origin main`).
4. تأكد من عدم رفع مجلد `node_modules/` أو ملف `.env` أو مجلد `data/`.

## خيارات النشر السحابي (Deployment)

لأن المشروع يعتمد على Node.js + SQLite بملف محلي، يُنصح بنشره على منصة تدعم القرص الدائم (Persistent Volume) مثل:
- **Railway** أو **Render** (مع ربط Persistent Disk على مسار `./data`) أو **VPS (Ubuntu + PM2 + Nginx)**.
- أوامـر النشر القياسية:
  - Build Command: `npm install && npm run build`
  - Start Command: `npm start`
